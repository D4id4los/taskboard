* What this document is

The *derived actor/edge model of the shipped runtime*: every channel,
task, and shared-state edge that exists in the code, with a
=file:line= anchor for each half. It is *release-anchored* —
regenerated as part of every release cut (see [[*Maintenance][Maintenance]]) — so the
anchors below describe one tree, not a moving target.

- *Derivation base:* code state of =76838a1= (=origin/main= at the
  time of derivation; the branch adding this file is docs-only).
- *Derivation date:* 2026-10-18.
- *Origin:* promoted from the v0.1.0 audit's flow-model chunk
  (=.artifacts/reports/2026-10-16-v0.1.0-audit-flow-model-report.md=),
  re-derived at the base above. The derivation reproduced the audit's
  topology exactly (23 production constructors, 13 actors, 36 edge
  rows); only line anchors moved.
- *Companion documents:* =docs/architecture.org= (the normative
  architecture prose) and the ADRs. Where this file and
  =docs/architecture.org= disagree about the topology, one of them is
  wrong — file an issue, never silently absorb the difference.

* Method — how to regenerate this document

Six passes, each a mechanical grep plus a reading pass. Reproduce them
from any clone at the derivation base. *Exclusion rule* (applies to
every pass): hits inside =#[cfg(test)]= modules, =tests/= directories,
and doc comments (=//!=, =///=) are not part of the shipped runtime
and are excluded.

1. *Channel constructors, workspace-wide.*

   #+begin_example
   grep -rn -E 'mpsc::channel|mpsc::unbounded_channel|broadcast::channel|watch::channel|oneshot::channel' crates/*/src --include='*.rs'
   #+end_example

   Filter per the exclusion rule. Expect **23 production constructor
   sites**: =bootstrap.rs= ×6, state =actor.rs= ×6, storage
   =actor.rs= ×3, ipc =server.rs= ×3, =repl.rs= ×4 (incl. the headless
   orphan), =ui.rs= ×1. =mpsc::unbounded_channel= must have **zero**
   production hits — that is a recorded invariant, not an assumption.

2. *Spawn sites.*

   #+begin_example
   grep -rn -E 'tokio::spawn|task::spawn|spawn_blocking|thread::spawn|thread::Builder|run_event_loop' crates/*/src --include='*.rs'
   #+end_example

   Filter per the exclusion rule; classify the rest into the actor
   inventory (below) or as non-spawn executors (the Slint event loop
   on the process main thread; the REPL session loop as an async
   future).

3. *Wiring trace.* From the three roots — =bootstrap()=
   (=bootstrap.rs:512=), =run_desktop= (=ui.rs:157=), =main::run=
   (=main.rs:79=) — follow each constructor half to its consumer by
   reading the owning function and its callers. Do not infer
   crossings; read them.

4. *ArcSwap writer/reader enumeration.*

   #+begin_example
   grep -rn -E '\.rcu\(|\.store\(|\.load_full\(\)|\.load\(\)' crates/*/src --include='*.rs'
   #+end_example

   Filter per the exclusion rule (watch for the false friend
   =CredentialStore::store=). Exactly **one** production write site
   may remain: =publish= in the state actor. More than one is a
   finding against the AGENTS §2 sole-writer rule.

5. *Shutdown routes.* Trace the four triggers (signal, =daemon stop=,
   UI window close/signal, REPL EOF/exit) into =App::shutdown= and
   record the implemented step order (below).

6. *Mode matrix.* Derive presence/absence of each actor per process
   mode from =main::run=, =bare_invocation_route= (=ui.rs:79=), the
   REPL entry (=repl.rs=), and the daemon mode gate (=main.rs:250=).

*Mermaid validation fallback:* when no =mmdc= is available, keep the
diagrams in a conservative label subset (ASCII labels, all labels
quoted, no bare =end= tokens, no exotic shapes beyond one =[( )]=
database node) and run a structural lint — balanced quotes and
brackets, declare-before-use for every node id. A parse-check with
mermaid's own parser is the preferred validation when tooling exists.

* Shutdown routes

** Triggers (pre-sequences)

| Trigger | Route into =App::shutdown= |
|---+---|
| =ctrl_c= / SIGTERM, daemon | =wait_for_signal= (bootstrap.rs:780) vs =server.stopped()= in the daemon =select!= (main.rs:306-313) → =server.join(timeout)= (server.rs:104; aborts accept+dispatcher at the budget, drains accepted connections) → =shutdown_from_arc= (main.rs:320, fn bootstrap.rs:753) → =app.shutdown()=. A second signal during the drain force-exits 130 (main.rs:326). |
| =taskboard daemon stop= | CLI IpcOnly lane (main.rs:95ff) → =Request::Shutdown= → IPCD answers and sets the stop watch (server.rs:165-169) → the daemon trigger above completes the sequence. |
| =ctrl_c= / SIGTERM, desktop | EXITW (ui.rs:194-198) calls =slint::quit= → loop returns → watcher+forwarder aborted (ui.rs:202-203) → =app.shutdown()= (ui.rs:204). |
| Window close, desktop | =run_event_loop= returns (lib.rs:266) → same ui.rs:202-204 path. |
| REPL =exit= / Ctrl-D / EOF | =repl_loop= breaks (repl.rs:528/533) → =app.shutdown()= (repl.rs:620); the dropped disposition sender is the editor thread's exit signal (repl.rs:235); =TtyStateGuard= restores termios on drop. |
| Detach (connector only) | =App::detach_connector= (bootstrap.rs:219): drain registry → =stop_actor= per actor (send =SyncCommand::Detach= :473, bounded join) — the rest of the graph keeps running. |
| Attach unwinding | A lost attach race unwinds the refused actor outside the lock (bootstrap.rs:293ff). |

** =App::shutdown= implemented order (bootstrap.rs:330-390)

#+begin_src mermaid
sequenceDiagram
  participant SRC as trigger
  participant APP as App::shutdown
  participant ENG as ENG engine
  participant SYN as SYN connector
  participant NTF as NTF notifier
  participant STO as STO storage
  SRC->>APP: shutdown self bootstrap.rs:330
  APP->>ENG: EngineEnvelope Flush receipt bootstrap.rs:348 actor.rs:157
  APP->>SYS: broadcast SystemEvent Shutdown bootstrap.rs:351
  Note over ENG: enters drain actor.rs:434 declines Execute and AttachConnector disarms reminder timer
  APP->>SYN: stop_actor Detach + bounded join bootstrap.rs:360-363 via :472
  APP->>APP: drop parked reports twin closes fan-in bootstrap.rs:370
  APP->>ENG: join_bounded engine_join bootstrap.rs:372
  APP->>NTF: join_bounded notifier_join bootstrap.rs:379
  APP->>STO: drop StorageHandle then storage_join await bootstrap.rs:384-385
#+end_src

Numbered, each step with evidence: (1) destructure =App= so the parked
reports twin's drop is structural (bootstrap.rs:335-347); (2)
=engine.flush()= — the durability barrier receipt (boot strapping
actor.rs:157) :348; (3) =system.send(SystemEvent::Shutdown)= :351 —
the engine's drain flip (state/actor.rs:434: declines
=Execute=/=AttachConnector=, disarms the reminder timer, keeps
ingesting sync reports until the channel closes) and the sync actor's
stop (sync/actor.rs:231); (4) per-connector =stop_actor= =
=SyncCommand::Detach= + bounded join with abort-at-budget
(bootstrap.rs:360-363 → =stop_actor= :472, =join_bounded= :482); (5)
=drop(reports)= — closes the fan-in inbox so the engine's
linger-drain can finish (:365-370); (6) bounded engine join :372; (7)
bounded notifier join :379 (the consumer would exit on its own — the
engine exit closed its channel); (8) =drop(storage)= then
=storage_join.await= (:384-385).

On the daemon path the call arrives through =shutdown_from_arc=
(bootstrap.rs:753, called from main.rs:320): the typed tail that
hands the core's exclusive ownership to the sequence above, returning
a typed runtime failure instead of panicking when a stray strong
reference pins the core.
