#+title: taskboard UX Surface Census
#+options: toc:t

This is the living app-scale capability × surface matrix plus every
standing ruling with its date and authority
(`docs/ux_planning.org` §2.4; the framework plan
`.artifacts/plans/2026-11-13-ux-journey-planning-framework-plan.md`
§4.4). Each UX journey plan updates its slice; each GUI review round
diffs against it. Overturning a ruling is a visible census diff made
at UX-plan level — never a chunk-local surprise.

- *Status*: =phase 3 in flight: task-flow surfaces complete=
  (2026-11-13) — the stock-take (dispatch
  `.artifacts/plans/2026-11-13-ux-census-stocktake-dispatch-plan.md`)
  has re-organized the phase-2 seed from feature-scoped slices into
  surface-scoped slices and completed the four task-flow surfaces
  (Board, Task detail, Today, Capture). The Review, Settings (files
  sync), alarm-window, and CLI slices are chunk 2's; absences outside
  the completed slices are *not* rulings.
- *Evidence convention*: every populated cell cites =file:line= at its
  slice block's recorded **Baseline** SHA (stated once per slice block,
  D-7) or an existing test name. Seed-derived cells inherit the seed
  baseline **=fb5863ed=** and keep it; drift between slice baselines is
  expected and recorded, never normalized. A cell the phase-2 pilot
  comparison marked deviating/missing carries its verdict marker; no
  such markers exist (the comparison found zero deviations —
  `.artifacts/plans/2026-11-13-round7-ux-pilot-comparison-plan.md` §1).
- *Columns* are the app's fixed surface set (Board / TaskDetail /
  Today / Review / Settings / Capture / CLI); =D= display, =E= edit,
  =C= create, =X= remove; =—= deliberately absent (a core-verb absence
  needs a ruling in the slice's block); =— (self)= the capability *is*
  that surface (not an absence, no ruling needed); =U= unruled absence
  — no authority ever ruled it (phase-4 triage input; each =U= has a
  row in the slice's *unruled register*).
- *Schema* (the stock-take chunk-1 decisions, recorded in
  `.artifacts/plans/2026-11-13-ux-census-stocktake-1-chunk-plan.md` §2,
  binding): slices are *surface-scoped* — one capability×surface matrix
  per surface, the column set never changes; capabilities are derived
  by the *verb-inventory method* (five extraction passes: engine
  `StateCommand` verbs, UI `UiRequest`s grouped per polling family,
  `ActionId` affordances bucketed by `ContextId`, CLI verbs, and
  display-only affordances), named =entity.verb= snake_case with the
  engine/clap word as naming authority; internal-commit action ids fold
  into the user-facing capability they commit (identity kept in the
  cell evidence); overlays are recorded inside the slice whose view
  mounts them, and the alarm window gets its own slice block (chunk 2,
  D-6); one capability = one row = one name across every slice that
  carries it; *complete* = every derived capability whose exposure lies
  even partly in the slice has a row and zero blank cells in the slice.
